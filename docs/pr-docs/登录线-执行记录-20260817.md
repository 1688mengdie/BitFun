### 补修沉淀（S-33）

- 现象：qoder 授权 nonce 两处独立生成（URL/轮询各一个）导致主链路必失败——**协议流中「同一标识贯穿多阶段」是设备码流核心不变量**，实现时必须让 URL 构造函数接收外部传入的 nonce 而非内部生成
- 根因：照抄 opencode 骨架时未注意到 opencode 的 nonce 由设备码响应返回、而 qoder 由客户端自行生成
- 绕过：URL 构造函数显式接收 nonce 参数 + 单测断言「URL nonce == 轮询 nonce」双向提取比对
- 教训：协议类任务的「阶段间共享标识」必须单测锁定，仅断言 URL 含字段 ≠ 断言字段一致
