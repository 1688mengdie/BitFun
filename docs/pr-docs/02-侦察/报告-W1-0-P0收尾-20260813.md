## 三、开发版侧改动（quant_tools.rs）

### 1. `QuantBacktestInput` 增加 `pipeline` 字段

```rust
pub struct QuantBacktestInput {
    pub config: String,          // BacktestConfig YAML
    pub csv_data: String,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub pipeline: Option<String>, // PipelineConfig YAML（可选）
    pub workspace_path: Option<String>,
    pub timeout_seconds: Option<u64>,
}
```

### 2. `call_impl` 双层透传

```rust
let mut message_body = json!({
    "config": params.config,
    "csv_data": params.csv_data,
});
if let Some(pipeline) = params.pipeline {
    message_body["pipeline"] = json!(pipeline);
}
let message = format!("run_backtest {}", message_body);
```

- `pipeline` 存在 → 作为顶层 RPC 参数传 lvpa（lvpa 写临时文件并覆盖 config 内 template）
- `pipeline` 缺省 → lvpa 保持 config 内 `pipeline_template` 路径（P0-c 回归兼容）
- description / input_schema 同步更新
