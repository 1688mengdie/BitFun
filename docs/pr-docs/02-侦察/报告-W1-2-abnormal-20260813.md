## 二、taiji-server RPC 域设计

### abnormal.score — 5 指标加权融合异常评分卡

```
params: {
  bars:        [{open,high,low,close,volume?,timestamp?}],  // 必填，K 线数组
  lookback?:   usize,                                        // 回溯窗口（缺省 30）
  weights?:    {vol_regime,vol_anomaly,corr_fracture,gap_alert,trend_accel},  // 和=1
  thresholds?: {warn,reduce,emergency},                      // warn<reduce<emergency
}
result: { score, level, thresholds, weights, indicators:{vol_regime,...}, bars_count }
```

- 5 节点纯函数：`VolRegimeNode`（20d HV vs 80 分位）/ `VolAnomalyNode`（10d 波动率 Z 分）/ `CorrFractureNode`（相关性断裂）/ `GapAlertNode`（跳空预警）/ `TrendAccelNode`（趋势加速度）
- 融合：`ScorecardFusionNode` 加权（默认 0.25/0.20/0.15/0.25/0.15）clamp[0,100]——**真实走 StateStore + on_bar 模式**（与能力 crate 测试同构，杜绝重复实现 + 单源真相）
- 阈值：`AbnormalLevel::from_score`（warn≥70 / reduce≥85 / emergency≥95），缺省 70/85/95
- 参数校验：缺失 bars → -32602；阈值乱序（warn≥reduce）→ -32602；权重和≠1 → -32602
- 同步 CPU 密集 → `spawn_blocking` 隔离（strategy.rs M-C 先例）
