# 报告：rad06 Phase 1 量化工具注册与接线（2026-08-13）

## 一、任务概述

将 taiji-lvpa 量化引擎接入 BitFun 工具系统，实现四工具全量注册与真实链路验证：

- **ACP 主通道**：`quant_backtest`（AcpClientPort → AcpClientService → spawn `taiji acp` → run_backtest）

### 3. 追加修复：builtin 客户端零配置 spawn 兜底

**发现问题**：`AcpClientService::resolve_start_client_config` 本地路径（`remote_connection_id=None`）只查 config 文件，不回落 builtin preset 默认配置 → 全新 `taiji-quant` 客户端无 config 条目时 `create_session` 报 `NotFound`。

**修复**：`manager.rs::load_configs()` 对 config 缺失的内置客户端注入 `default_config_for_builtin_client()` 默认配置（用户条目优先，不覆盖）。与 remote 路径（line 2265 已回落 builtin）语义一致。
