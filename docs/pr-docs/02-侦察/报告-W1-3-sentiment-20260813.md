## 二、能力面细节

### 2.1 词典加载（W1-3 判定要点）
- taiji-sentiment 内置词典 `config/sentiment_dict.json` 为 `{entries: [...]}` 包装结构（58 条），
  而 `from_json` 期望裸数组 → 新增 `from_builtin_dict()`：`include_bytes!("../config/sentiment_dict.json")`
  → 剥离 `entries` → 透传 `from_json`。编译期绑定，无运行时 IO。
- jieba 构造成本高 → RPC 层 `OnceLock<Arc<SentimentTokenizer>>` 进程级单例（sentiment.rs）。

### 2.2 RPC 契约
- `sentiment.analyze {text}` → `{score∈[-1,1], confidence∈[0,1], positive_words[], negative_words[], policy_keywords[]}`；缺 text → -32602。
- `sentiment.fgi {hv20?, commodity_momentum?, oi_change_rate?, basis_slope?, nlp_sentiment?}` → `{fgi∈[0,100], category, factor_weights}`；因子缺省 50.0 中性；分类阈值 0-25 极度恐惧 / 25-45 恐惧 / 45-55 中性 / 55-75 贪婪 / 75-100 极度贪婪。

### 3.2 9527 真实连通性（非 mock）
启动 `cargo run -p taiji-server`（监听 http://127.0.0.1:9527）后真实 HTTP 调用：

```
POST /api/rpc  sentiment.analyze {"text":"央行降息刺激经济，市场强势突破，看好后市"}
→ {"score":0.72, "confidence":0.4545, "positive_words":["降息","刺激","强势","突破","看好"],
   "policy_keywords":["降息","刺激"], "negative_words":[]}

POST /api/rpc  sentiment.fgi {五因子 50/100/50/50/50}
→ {"fgi":62.5, "category":"贪婪", "factor_weights":{hv20:0.25, commodity_momentum:0.25,
   oi_change_rate:0.2, basis_slope:0.15, nlp_sentiment:0.15}}
```

- sentiment.analyze 由真实 jieba 分词 + 内置词典驱动（score=0.72 命中 5 词）。
- sentiment.fgi 加权复算 62.5 与公式一致（12.5+25+10+7.5+7.5）。
- 注：PowerShell `Invoke-RestMethod` 直接发中文 body 会被本地编码破坏（fgi 分类显示乱码、
  analyze score=0）；改 UTF-8 字节流后正常——属客户端编码问题，非服务端缺陷。
