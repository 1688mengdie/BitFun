## 二、taiji-server RPC 域设计

### content.render — K 线 PNG 纯函数渲染（base64）

```
params: {
  bars:       [{open,high,low,close,volume?,timestamp?}],  // 必填；最后一根 = 当前 bar，其余 = 前导上下文
  width?:     u32   // 默认 400；clamp [12, 1600]
  height?:    u32   // 默认 300；clamp [12, 1600]
  indicators?:{name: value}  // 可选；底部指示条（非有限值跳过）
}
result: { png_base64, bars_count, sanitized_nan, frame_type: "full"|"empty" }
```

- **纯函数**：KLineRenderer 无内部状态，handler 直调能力层，无 AppState 新增字段
- **NaN/Inf 处理**：前向填充（渲染器 L9-28）+ `sanitized_nan` 如实计数（本域复算，与渲染器同源逻辑）
- **空帧兜底**：首根非有限且无前序 → 渲染器返回空帧 PNG，`frame_type="empty"` 如实登记（不 panic 不虚构）
- **画布 clamp**：`width/height` clamp [12, 1600]，防超大画布内存/响应体无界
- **spawn_blocking**：CPU 密集同步渲染隔离，防阻塞 tokio worker（abnormal.rs L80 先例）
- **边界**：不碰 ffmpeg/文件系统/RTMP——合成（FfmpegComposer）/直播（LiveStreamEngine）/定时任务（VideoScheduler）留幻梦池六步管线（workshop_dream.rs 已接线）
