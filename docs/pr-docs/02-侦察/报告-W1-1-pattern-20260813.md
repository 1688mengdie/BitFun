## 二、taiji-server RPC 域设计

### pattern.chan — 缠论 18 类买卖点

```
params: {
  bars?: [{open,high,low,close,volume?,timestamp?}],  // 全管线：分型→笔→中枢→线段→背驰→买卖点
  bis?:  [{start_index,end_index,direction,start_price,end_price}],  // 直传笔，跳过前段
  macd?: [f64]                                          // 背驰 MACD 分量（缺省全 0 → 如实退化）
}
result: { bars_count, fractals, bis, hubs, segments, divergences, buy_points, sell_points }
```

- 管线：`detect_fractals → detect_bi → ChanHubDetector::detect → SegmentDivider::divide → DivergenceAnalyzer::check(Any) → BSPDetector::detect`
- 背驰对构造：线段合成笔（`segment_bi`：段内首笔起点价 + 末笔终点价 + 线段方向/区间）
- 缺失参数 → `RpcError::InvalidParams`（-32602）

### pattern.dtw — 多维 DTW 相似度

```
params: { query: [[f,...],...], template: [[f,...],...], window?: usize, feature_weights?: [f64] }
result: { distance, lb_keogh, query_len, template_len, feature_count }
```

- `DtwEngine::distance`（加权欧氏 + Sakoe-Chiba band）+ `lb_keogh` 下界
- 同步 CPU 密集 → `spawn_blocking` 隔离（strategy.rs M-C 先例）
